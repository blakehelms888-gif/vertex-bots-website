# Vertex Bots website starter

This is a responsive static website starter for Vertex Bots.

## Files
- `index.html` — website content and sections
- `styles.css` — dark navy / blue responsive design
- `script.js` — mobile navigation and project-request form

## Preview locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create or open a GitHub repository for the website.
2. Upload all three website files (`index.html`, `styles.css`, `script.js`) to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will show the published website address in the Pages section.

## Important notes
- The project request form is front-end only. It prepares a request summary for the visitor to copy and submit in the Vertex Bots Discord. It does not store or send customer information to a server.
- No pricing has been added because Vertex Bots pricing has not been finalized.
- The Discord invite currently points to `https://discord.gg/2DkGYnmfpp`.
- A custom domain such as `vertexbots.com` must be registered separately; free hosting does not provide ownership of a `.com` domain.
